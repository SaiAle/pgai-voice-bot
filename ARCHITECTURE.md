# Architecture

The Python caller uses LiveKit Agents 1.8.2 in pipeline mode: Deepgram Nova-3 transcribes incoming telephone audio, Groq hosts the text-only GPT-OSS-20B model, and Deepgram Aura-2 synthesizes the patient replies. Silero detects speech. LiveKit SIP connects the room to the assessment number. Patient instructions are passed to the language model, never spoken as a greeting. Streaming speech recognition reduces the waiting inherent in batch transcription; separate providers keep the stages measurable and replaceable. Groq and Deepgram replace the earlier OpenAI API setup, whose exhausted credit balance blocked the live test.

The caller restricts the destination to the assessment test number and checks model availability before dialing. The agent uses LiveKit turn handling and interruption support and requests two-sided recording. Completed sessions export OGG audio, timestamped transcripts, and a JSON session report to calls/. A live transcript is also saved incrementally for diagnosing interrupted runs. Real-call conversation quality and export completeness must be verified before counting calls toward submission. Free-tier rate limits and telephony costs remain external constraints; this is an assessment prototype rather than a production service.
